# Customer-churn-prediction-week2
Customer Churn Prediction using Machine Learning
Overview

This project uses Machine Learning to predict whether a customer will leave a company based on customer data. It helps businesses identify customers who are likely to churn and improve retention strategies.

Features

Data preprocessing
Decision Tree and Random Forest models
Train and test data splitting
Model accuracy evaluation
Confusion Matrix visualization
ROC Curve analysis
Customer churn prediction

Technologies Used

Python
Google Colab
Pandas
NumPy
Matplotlib
Scikit-learn

How to 

Open the notebook in Google Colab.
Upload the customer churn dataset.
Run all the cells.
View the model performance and predictions.

Expected Outcome

Build a supervised learning model for customer churn prediction.
Compare machine learning algorithms.
Learn model evaluation using accuracy, confusion matrix, and ROC curve.
